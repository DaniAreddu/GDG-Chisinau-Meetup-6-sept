# Building On-Device AI Agents with Gemini ADK

Slides from my session at **GDG Chișinău**, delivered on **6 September 2026**.

## About the session

This talk explores how to build AI agents that operate closer to the user by combining **Gemini** with the **Google Agent Development Kit (ADK)**.

It covers the architecture of agentic applications, tool integration, local and on-device execution patterns, and the trade-offs between cloud intelligence and edge capabilities.

## Topics covered

* Agentic AI and autonomous agents
* Gemini and Google ADK fundamentals
* Tools, orchestration, and agent workflows
* Cloud-to-edge and on-device AI architectures
* Privacy, latency, resilience, and offline capabilities
* Practical implementation considerations
